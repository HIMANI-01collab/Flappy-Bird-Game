
# 🐦 Flappy Bird - Python

A classic Flappy Bird game built using Python and Pygame.

## Features
- Animated bird
- Gravity and jumping mechanics
- Randomly generated pipes
- Collision detection
- Score tracking
- High score saving
- Game restart functionality

## Technologies Used
- Python
- Pygame

## Installation

Clone the repository:

    git clone YOUR_GITHUB_REPOSITORY_URL

Install dependencies:

    pip install -r requirements.txt

Run the game:

    python main.py

## Controls
- SPACE: Jump
- R: Restart
- ESC: Quit
